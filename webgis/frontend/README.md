# ForestWatch Papua WebGIS Frontend

Frontend React + Vite untuk gambaran awal dashboard WebGIS ForestWatch Papua.

## Jalankan Lokal

```bash
npm install
npm run dev
```

Default data memakai file dummy di folder `dummy-data/`. Jika backend FastAPI sudah jalan, set:

```bash
VITE_API_URL=http://localhost:8000
```

Lalu jalankan ulang dev server.
